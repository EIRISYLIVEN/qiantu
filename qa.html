答辩问答准备

常见追问 + 建议回答口径。回答要短、稳、落到「可落地」三个字。

Q1 微信/支付宝不开放账单接口，你们的数据怎么获取？

这正是我们最大的技术难点，我们没有回避。全自动抓取在金融合规下走不通，所以我们走三条务实路线：

  • A 手动记账 —— 几秒记一笔，最简单、100% 可控；
  • B 账单导入 + AI 识别 —— 经用户授权后，导入其自行导出的 CSV/邮件/截图，AI 自动解析成账目；
  • C 购物平台 API —— 对接淘宝/京东/拼多多开放平台，作为远期方向。

MVP 阶段用 A + B 起步，先跑通闭环。

Q2 和随手记、鲨鱼记账、钱迹有什么区别？

它们普遍存在五个不足：功能臃肿、只记录不指导、依赖联网、数据割裂、缺乏公共安全属性。

《钱途》用「极简 + 离线优先 + 多渠道聚合 + AI 开源节流 + 安全护航」做差异化——别人记流水账，我们做理财顾问；别人依赖联网，我们离线优先；别人只做工具，我们兼做公共服务。

Q3 为什么选「豆包」，而不是更专业的金融 AI？

做减法。我们的用户是普罗大众，你问农村中老年人什么是「AI」，他可能不知道，但豆包是国民级应用，家喻户晓。选大众熟知的国民级 AI，能让「AI 记账分析」对普通用户没有认知门槛，用起来更亲切、更可信。

Q4 免费怎么盈利？模式能落地吗？

分三步走——

  • 短期：免费工具，专注打磨核心体验、积累口碑；
  • 中期：会员订阅制（高级分析、家庭账本、无限 AI 建议、更多导入方式），这是主要收入来源；
  • 长期：金融增值服务（与持牌机构合作的理财教育、优惠比价、信用管理）+ 企业合作（消费行为洞察）。
Q5 用户隐私怎么保证？

坚持「先授权、后读取」——账单导入、订单对接等任何涉及读取记录的操作，都须用户明确授权后才进行；数据本地加密存储、可随时撤销授权，把隐私主动权交还给用户。

Q6 反诈和记账理财有什么关系？

我们借鉴「国家反诈中心」等官方 APP 的成熟做法，定期推送反诈宣传与网络安全提示（识别陌生转账、防范电信诈骗、警惕钓鱼链接）。记账理财之外主动承担社会责任，也契合大赛公共服务赛道的定位。

Q7 技术难度大吗？开发进度怎么保证？

技术栈都是成熟的——Flutter/uni-app + SQLite + 云数据库 + 豆包 API，风险低、文档丰富、成本可控。MVP 聚焦 P0 六项 + 5 个主界面，体量可控，适合 5 人小团队分模块协作，符合大赛「团队 ≤5 人」的要求。

Q8 「开源节流」分析具体怎么实现？

不做复杂的金融建模，就是双向诊断——收入侧看「如何开源」、支出侧看「如何节流」，最后用「一句话 + 一条可执行建议」的形式输出，把冷冰冰的数字变成用户看得懂、能照着做的理财建议。

通用提醒

  • 节奏每个回答控制在 20–30 秒，先给结论、再给一句支撑。
  • 坦诚遇到不会的，坦诚说「这是我们正在完善的方向」，不要硬编。
  • 关键词反复落到三个词：极简、离线优先、可落地。
