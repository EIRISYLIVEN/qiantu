# 钱途 · 记账理财 APP

> 极简记账 · 离线优先 · 多渠道聚合 · AI 开源节流 · 安全护航

《钱途》是一款面向普通人的记账理财 App——不止记录，更做分析，把记账从「记录工具」升级为「理财顾问」。本项目是**湖北大学第十二届 APP 创意大赛**「细水长流」开发团队的参赛作品，含路演官网、答辩问答与术语大白话对照表。

---

## 一句话定位

> 帮普通人**看清钱、管住钱**，缓解金钱焦虑、引导适度消费、避免超前消费。

## 创意来源 · 三大痛点

移动支付让花钱变成无感扫码，钱花出去没有手感、没有痕迹：

1. **「钱去哪了」说不清** —— 微信、支付宝、银行卡、现金、花呗多渠道各记各账，没有一个统一账本；
2. **「月底才傻眼」** —— 缺少实时、可视化的收支趋势，月末才发现超支；
3. **「想省钱却无从下手」** —— 知道该省，却不知道该从哪一类支出下手。

## 五大核心特色

| 特色 | 说明 |
|---|---|
| 🍃 极简 | 只保留 5 个主界面，「记一笔」3 秒内完成 |
| 📶 离线优先 | 数据先存本地，无网络照常记账，联网自动同步 |
| 🔗 多渠道聚合 | 把分散多渠道的收支统一到一个账本 |
| 🤖 AI 开源节流 | 收入侧「开源」+ 支出侧「节流」，一句话 + 一条可执行建议 |
| 🛡️ 安全护航 | 先授权后读取、本地加密、反诈推送，兼做公共服务 |

## 技术方案

- **客户端**：Flutter / uni-app 跨平台，一套代码适配安卓与 iOS
- **本地存储**：SQLite 本地数据库，数据先写本地、离线优先
- **云端同步**：联网自动上传云数据库，多端同步与备份
- **AI 能力**：调用豆包等通用大模型 API，无需自研模型

> 最大难点：微信/支付宝不开放账单接口。三条务实路线 —— A 手动记账、B 账单导入 + AI 识别、C 购物平台 API（远期）。MVP 用 A + B 起步。

## 六大核心创新

1. **开源节流双引擎** —— 首创「开源 + 节流」双引擎
2. **离线优先 + 联网同步** —— 弱网/无网照常记账
3. **动态实时新手引导** —— 出现一处、点一下，边点边学
4. **豆包 AI 做减法** —— 国民级 AI，认知门槛低
5. **先授权 · 后读取** —— 本地加密存储、可随时撤销
6. **反诈安全护航** —— 借鉴国家反诈中心，承担社会责任

## 本地预览

直接双击 `index.html` 即可用浏览器打开；或起一个本地静态服务：

```bash
# Python 3
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 部署到 GitHub Pages

1. 将仓库推送到 GitHub；
2. 仓库 **Settings → Pages**，Source 选择 `main` 分支 + `/ (root)` 目录；
3. 保存后即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。
