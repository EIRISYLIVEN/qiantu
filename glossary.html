英文术语 · 大白话对照表

把 PPT 里所有英文缩写、技术名词、商业术语，以及「听起来高深」的词语逐条翻译成大白话。

一、英文缩写

APP
全称 Application，就是「应用程序」，手机/电脑桌面上那个图标点开的软件。「记账理财 APP」＝一个记账理财的手机应用。
AI
Artificial Intelligence，人工智能。让电脑像人一样「看得懂、想得到、会给建议」。PPT 里「AI 开源节流 / AI 建议」，就是用 AI 自动帮你分析收入和支出、给出「怎么省钱、怎么增收」的具体建议。
P0 / P1 / P2
优先级等级（Priority）。P0 最高＝第一版必须先做；P1＝第二期再做；P2＝以后慢慢加。类似「先保命，再改善，最后锦上添花」。
MVP
Minimum Viable Product，最小可行产品。先做出一个「够用、能跑通」的最简版本赶紧上线验证想法，别一上来就憋大招，验证对了再逐步加功能。
API
Application Programming Interface，应用程序接口。别人开给你的「官方数据/功能通道」。比如「豆包 API」＝字节跳动开给你调用豆包 AI 的官方通道；「微信/支付宝不开放账单接口」＝他们没有官方通道让你直接读用户账单。
CSV
Comma-Separated Values，逗号分隔值文件。一种最朴素的表格文本：一行一条记录、列用逗号隔开，Excel 能直接打开，常用来导入导出账单。
UI
User Interface，用户界面。就是 App 长什么样、按钮怎么摆、配色好不好看。「UI 设计」＝界面设计。
iOS
苹果手机（iPhone）和平板（iPad）用的操作系统。「适配安卓与 iOS」＝安卓机和苹果机都能装。

二、技术名词

Flutter
谷歌出的跨平台开发框架。用一套代码同时生成安卓版和苹果版两个 App，省一半工作量。
uni-app
国产跨平台框架（DCloud 出品），作用同 Flutter：一套代码跑安卓 + 苹果 + 小程序。
SQLite
一种轻量级本地数据库，相当于「存在手机里的小型账本文件」，不用联网、打开就用，正好配合「离线优先」。
云同步 / 云数据库
把数据存到网上的服务器（云端），换手机、多设备之间自动同步和备份。
技术栈
一个项目用到的一整套技术组合。PPT 里的技术栈＝Flutter/uni-app + SQLite + 云库 + 豆包 API。

三、产品与商业名词

离线优先
设计原则：数据先存本地，不联网也能照常记账，联网后再自动同步。解决「没网就歇菜」的痛点。
多渠道聚合
把微信、支付宝、银行卡、现金、花呗这些分散的账，收拢到一本总账里，还原「钱的全貌」。
差异化定位
和竞品拉开区别、找到自己的独特卖点。PPT 的核心是「别人记流水账，我们做理财顾问」。
竞品分析
分析同类对手（随手记、鲨鱼记账、钱迹等）的优缺点，找到自己的机会点。
会员订阅制
按月/年付费解锁高级功能的会员模式。
金融增值
在记账基础上，叠加理财教育、优惠比价、信用管理等增值服务来赚钱。
闭环
一个首尾相连、能自我循环的完整流程：记→存→看→分析→再记，形成正反馈。
反诈
反电信网络诈骗。PPT 里指借鉴「国家反诈中心」App，定期推送防骗、网络安全提示，承担社会责任。

四、成语与「高深词」

开源节流
开源＝增加收入来源；节流＝减少不必要的支出。「AI 开源节流双引擎」＝AI 同时从「多赚钱」和「少花钱」两头帮用户。
极简
去掉多余功能、只留核心。PPT 里指只保留 5 个主界面、「记一笔」3 秒内完成。

五、真实产品 / 品牌名（答辩常被问到）

豆包
字节跳动（抖音母公司）出的国产 AI 大模型，相当于「国产版 ChatGPT」。选它是因为国民度高、中老年也认识、认知门槛低。
花呗
支付宝旗下的消费信贷产品（先花后还），属蚂蚁集团，真实存在。
随手记 / 鲨鱼记账 / 钱迹
三款真实存在的主流记账 App，PPT 里作为竞品对比。
